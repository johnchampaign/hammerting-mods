[h1]Hammerting Fix-Up Mods: 53 bug fixes, reachable victories and a new research victory[/h1]

Hammerting stopped getting updates after 1.0, and it still has crashes, soft-locks, dwarves who wander into lava, hauling loops and two victory conditions that are practically out of reach. I played it through to the end and fixed what I hit along the way. The result is a free, open-source set of 53 mods.

[b]Download:[/b] [url=https://github.com/johnchampaign/hammerting-mods/releases/latest]github.com/johnchampaign/hammerting-mods[/url] (choose "Source code (zip)")
[b]Latest version:[/b] 1.6.5 (18 November 2026)

No game files are included. The installer reads your own copy of the game and patches it on your PC, keeping the original files as a backup. Existing saves keep working.

[h2]What's new in 1.6[/h2]
[list]
[*]The mods now speak all ten of the game's languages: French, Italian, German, Spanish, Russian, Simplified Chinese, Japanese, Polish and Brazilian Portuguese as well as English. Before, players in other languages saw raw names such as MAINMENU_HMOD_MODS where a mod added a text, and the game's old wording where a mod changed one.
[*]All mod texts, including the Mods window and the mods' section of the news, follow the language you pick in the game's Options (1.6.3; before, those two windows kept the language the game had when you ran the installer).
[*]The translations were made with an AI model, using the game's own terms. Corrections from native speakers are welcome on GitHub or in this thread.
[*]1.6.2: opening and closing the language list in Options no longer crashes the game. The mods had been saving some of the game's text tables in a damaged form since early versions.
[*]1.6.4: the news window at startup lists every release of the mods, not only the latest three.
[*]1.6.5: rough gems have their name and icon again and can be cut further. Every cut now keeps the gem's kind, so a Star of Mara takes 9 gems of one kind (still not 243). Gems cut as nameless before stay that way.
[/list]

[list]

[h3]Crashes and soft-locks[/h3]
[list]
[*]No more crash when completing faction alliance quests such as Dwarven Licorice.
[*]A Hammerting meeting starts within 2 minutes even if someone can't reach their seat.
[*]Plants no longer freeze at a growth stage.
[*]Quarries repair themselves, so a broken quarry can't lock up the colony.
[*]Dwarves cut off by a closed route are sent back to the entrance.
[*]Invader pile-ups are capped, and autosaves come every 15 minutes instead of 5.

[list]
[*]Storages pick up loose items, so mined ore, harvests and food stop rotting on the floor.
[*]Haulers keep their load when interrupted instead of dropping it, and goods you buy at a settlement actually get fetched.
[*]Stored items no longer suddenly rot in large colonies.
[*]Production queues stop locking up the colony's food and water, and Local Maintain stops at a sensible stock level instead of crafting forever.
[*]Buildings accept mixed materials, craft slots don't get stuck holding mixed gems, and the fishing pier stores its catch.

[h3]Dwarves[/h3]
[list]

[*]Ripe crops are harvested promptly instead of standing until you press Harvest on each plant.
[*]First tools are equipped automatically, and failed tool upgrades no longer reserve the tool for good.
[*]Dwarves heal slowly on their own, and wounded dwarves follow attack orders.

[h3]Lava, rails and missions[/h3]
[list]
[*]Dwarves don't walk into lava and walk out if it reaches them. Furnaces don't burn the lava you need for Sulphur Sprouts, and a lava pump isn't stopped by stored water.
[*]Handcar fixes: riders don't get stuck in queues, don't fight from a moving cart, and keep their place in line. The unfinished left-rising incline rail is added to the build menu.
[*]Land Survey unlocks early, so you can't lock yourself out of Mountain Lore. Discovery missions count rooms you found before the mission started. Dwarven Subversion is only offered at capitals you have found.

You can leave out any mod you don't want. The GitHub page describes each one in detail, including how it was tested.

[h2]How to install[/h2]
You need [url=https://www.python.org/downloads/]Python 3[/url] (3.10 or newer). On Windows, tick "Add python.exe to PATH" when installing it.

[olist]
[*]Download the zip from the [url=https://github.com/johnchampaign/hammerting-mods/releases/latest]releases page[/url] and unzip it anywhere.
[*]Close Hammerting.
[*]Windows: double-click [b]install.bat[/b]. Linux: run [code]./install.sh[/code] in the unzipped folder (see Playing on Linux below).
[*]In Steam, right-click Hammerting > Properties > General > Launch Options, and paste:
[code]%command% --game-extra-archives danger_zone/hammerting_mods.wkz[/code]
[*]Play!
[/olist]

The installer finds the game through Steam. If it can't, set the HAMMERTING_DIR environment variable to the game folder (the one containing game.wkz).

[b]Choosing mods:[/b] mods\recommended.txt lists what gets installed. Delete a line and run the installer again to leave that mod out.

[b]Smaller map:[/b] to have the Underworld closer, pick Mountain Size: Small when you start a new game (800 x 800 tiles instead of the default 1088 x 1088).

[b]Updating:[/b] download the new zip and run the installer again. It always patches from your original game files.

[b]Uninstall:[/b] double-click [b]uninstall.bat[/b] (Linux: [code]./uninstall.sh[/code]), then clear the Launch Options. Steam's "Verify integrity of game files" also restores the original game files.

[h2]Playing on Linux[/h2]
Hammerting has no Linux build, but it runs well under Proton, and the mods were developed and tested there.
[olist]
[*]In Steam, right-click Hammerting > Properties > Compatibility, tick "Force the use of a specific Steam Play compatibility tool" and pick [b]Proton Experimental[/b]. Start the game once without mods, then quit.
[*]Check you have Python 3 ([code]python3 --version[/code]); most distributions include it.
[*]Unzip the release and run [code]./install.sh[/code] in that folder.
[*]Set the Launch Options as above.
[/olist]
If your game is in an unusual place, run [code]HAMMERTING_DIR=/path/to/Hammerting ./install.sh[/code]. Steam Deck Desktop Mode should work the same way, but I haven't tried it.

[h2]Troubleshooting[/h2]
[list]
[*][b]The game closes without a message when it saves.[/b] Windows Security's Controlled folder access (Virus & threat protection > Ransomware protection) can block the game from writing its saves to Documents. Use "Allow an app through Controlled folder access" and add boot.exe from the Hammerting folder. Other antivirus programs, or a Documents folder kept in OneDrive, can cause the same.
[*][b]Is it the mods?[/b] Run uninstall.bat and try again. Clearing the Launch Options isn't enough, because the installer also patches the game's DLLs. Steam's "Verify integrity of game files" also gives you the unmodded game.
[/list]
